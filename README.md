## About Me

I'm a **Software Engineer, Software Architect, and Technical Lead**
with experience designing, developing, and maintaining enterprise
software solutions.

My professional background is primarily built around **C#/.NET,
Angular, cloud technologies, and distributed systems**, with
experience spanning the complete software development lifecycle.

Throughout my career, I've worked on:

- Designing software architectures, reusable components, and engineering standards.
- Developing enterprise applications, REST APIs, and microservices.
- Modernizing legacy applications and migrating systems to modern technologies.
- Building cloud-based and serverless solutions using Microsoft Azure.
- Implementing CI/CD pipelines, automated testing, and quality practices.
- Integrating enterprise systems and external services.
- Collaborating with developers, QA engineers, product teams, and stakeholders.
- Developing reusable libraries to simplify software engineering.

Beyond enterprise development, I'm passionate about **open-source software
and developer tooling**.

I've published libraries across the **.NET and Dart/Flutter ecosystems**,
focusing on intuitive APIs, lightweight implementations, extensibility,
and long-term maintainability.

I enjoy understanding complex problems and transforming them into
practical, reusable, and well-structured solutions.

One of my main interests is developing reusable tools and libraries

My open-source work spans the **.NET/C# and Dart/Flutter ecosystems**.

I focus on building libraries with:
